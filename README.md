# Kopi Jago — Official Website Starter

A responsive, interactive marketing website for Kopi Jago, a mobile coffee-cart brand. Built with plain HTML, CSS, and JavaScript — no build tools or dependencies required.

## Run locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `kopi-jago-website`).
2. Upload `index.html`, `style.css`, `script.js`, and this README (keep the file structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your public URL will appear in the Pages section.

## Before publishing — important edits

- In `script.js`, replace `6281234567890` with the official WhatsApp number, including country code and without `+` or spaces.
- In `index.html`, update the sample drink names, descriptions, and prices to match the actual Kopi Jago menu.
- Update the sample weekly route locations and operating hours in the **Find Us** section. These are placeholders, not live tracking.
- Replace the Instagram/TikTok placeholder links with official social accounts.
- Replace the stock photos with approved Kopi Jago cart, drinks, and team photos for a more authentic official-brand presence.

## Features

- Responsive desktop and mobile navigation
- Animated scroll reveal and moving brand ticker
- Filterable drink menu
- Product quick-order modal with WhatsApp handoff
- Mobile-friendly layout and reduced-motion support
- No framework, build step, or package installation required

## Notes

The menu, pricing, route schedule, phone number, and social links are sample content. WhatsApp ordering opens a prefilled message; it does not process payments or confirm orders automatically. Location schedule is static until connected to a real data source.
