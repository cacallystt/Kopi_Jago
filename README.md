# Kopi_Jago
Kopi Jago merupakan perusahaan yang bergerak di bidang industri Food and Beverage (F&amp;B), khususnya dalam penyediaan berbagai pilihan minuman kopi dan non-kopi berkualitas dengan konsep mobile coffee cart. Mengusung konsep bisnis yang praktis, modern, dan dinamis, Kopi Jago hadir secara berkeliling untuk menjangkau pelanggan di berbagai lokasi
